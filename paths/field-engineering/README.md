# Field Engineering

The customer-facing half of the job: discovery, qualification and sizing, performance testing engagements, POCs, migration, commercials and security, and escalation. The technical depth it leans on lives in the other parts and is linked, not repeated.

**For**: Sales engineers, solutions architects, and forward deployed engineers.

**Included in**: [Superstar FDE](../superstar-fde/). Progress made here counts there too.

The stages, their chapters, and what "done" means for each are in [`path.tsv`](path.tsv).

```bash
practice/bin/ol learn field-engineering          # stages and progress
practice/bin/ol learn field-engineering next     # read the next unfinished stage
```
