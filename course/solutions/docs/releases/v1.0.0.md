## Release procedure

1. Confirm `CHANGELOG.md` contains the complete `1.0.0` entry and all compatibility notices.
2. Confirm the working tree is clean and the full CI workflow passes on the release commit.
3. Create the annotated tag with `git tag -a v1.0.0 -m "Release v1.0.0"` and push the tag.
4. Record the resolved tag target and the release workflow run URL in this evidence file.
5. Publish only after the tag workflow succeeds. If any step fails, stop and follow the rollback procedure above.
