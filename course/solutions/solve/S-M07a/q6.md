# S-M07a q6

Claim: for any events $A, B$ in a probability space $(\Omega, P)$, $P(A \cup B) = P(A) + P(B) - P(A \cap B)$.

Method: split each set into disjoint pieces and apply the third axiom (additivity for pairwise disjoint events; a finite union is a countable one padded with empty sets, and $P(\emptyset) = 0$ follows from additivity applied to $\emptyset = \emptyset \cup \emptyset \cup \dots$ with $P \ge 0$).

Write $B \setminus A = B \cap A^c$.

1. $A \cup B = A \cup (B \setminus A)$, and $A$ and $B \setminus A$ are disjoint (an element of $B \setminus A$ is not in $A$). By additivity, $P(A \cup B) = P(A) + P(B \setminus A)$.
2. $B = (A \cap B) \cup (B \setminus A)$, and these two are disjoint (one is inside $A$, the other outside it). By additivity, $P(B) = P(A \cap B) + P(B \setminus A)$, so $P(B \setminus A) = P(B) - P(A \cap B)$.
3. Substituting step 2 into step 1: $P(A \cup B) = P(A) + P(B) - P(A \cap B)$.

Every step used only set identities and the additivity axiom, so the identity holds for all events $A$ and $B$.
