# S-M09a q11

Claim: for $x \in \mathbb{R}^n$ and every real $c$, $\mathrm{softmax}(x + c\mathbf{1}) = \mathrm{softmax}(x)$, where $\mathrm{softmax}(x)_i = e^{x_i} / \sum_{j} e^{x_j}$. With $c = -m$, $m = \max_j x_j$, every exponent $x_i + c$ is at most 0, so no term overflows, and the denominator is at least 1.

Method: direct computation, then a bound on each term.

Shift invariance: using $e^{a + b} = e^a e^b$,
$$\mathrm{softmax}(x + c\mathbf{1})_i = \frac{e^{x_i + c}}{\sum_j e^{x_j + c}} = \frac{e^{c} e^{x_i}}{e^{c} \sum_j e^{x_j}} = \frac{e^{x_i}}{\sum_j e^{x_j}} = \mathrm{softmax}(x)_i,$$
where cancelling $e^c$ is allowed because $e^c > 0$.

Bounds with $c = -m$: for every $i$, $x_i \le m$, so $x_i - m \le 0$ and $0 < e^{x_i - m} \le 1$. No term can overflow, whatever the size of $x$. The index $k$ with $x_k = m$ contributes $e^0 = 1$, and every other term is positive, so the denominator $\sum_j e^{x_j - m} \ge 1$: it is never 0, and the division never produces $\infty$ or NaN. (The denominator is at most $n$, also finite.)

Without the shift, $e^{x}$ overflows float32 for $x$ above about $88.7$ and float64 above about $709.8$, and $\infty / \infty$ is NaN: the failure of q8(b). With it, the exact same mathematical value is computed from numbers in $(0, 1]$. So shifting by the maximum changes nothing mathematically and removes overflow, which is how `M09.2`'s `softmax` and `logsumexp` are written.
