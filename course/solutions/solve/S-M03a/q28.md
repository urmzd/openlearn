**Claim.** For an $m \times n$ matrix $A$, the null space $N(A) = \{x \in \mathbb{R}^n : Ax = 0\}$ is a subspace of $\mathbb{R}^n$.

**Proof (direct, checking the three subspace conditions).** Matrix multiplication is linear: $A(x + y) = Ax + Ay$ and $A(cx) = c(Ax)$ for all $x, y \in \mathbb{R}^n$ and scalars $c$. *Zero:* $A0 = 0$, so $0 \in N(A)$. *Addition:* if $Ax = 0$ and $Ay = 0$, then $A(x + y) = Ax + Ay = 0 + 0 = 0$, so $x + y \in N(A)$. *Scaling:* if $Ax = 0$ and $c$ is a scalar, then $A(cx) = c(Ax) = c\,0 = 0$, so $cx \in N(A)$. $N(A)$ is a nonempty subset of $\mathbb{R}^n$ closed under addition and scalar multiplication, so it is a subspace of $\mathbb{R}^n$.
