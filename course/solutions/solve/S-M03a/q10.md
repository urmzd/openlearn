**Claim.** If the $n \times n$ matrix $A$ is invertible, then for every $b \in \mathbb{R}^n$ the system $Ax = b$ has exactly one solution.

**Proof (direct, existence then uniqueness).** Let $A^{-1}$ be the inverse: $A^{-1}A = AA^{-1} = I$. *Existence:* put $x = A^{-1}b$. Then $Ax = A(A^{-1}b) = (AA^{-1})b = Ib = b$ by associativity, so $x$ is a solution. *Uniqueness:* suppose $Ax = b$ and $Ay = b$. Then $A(x - y) = Ax - Ay = 0$, and multiplying on the left by $A^{-1}$ gives $x - y = (A^{-1}A)(x - y) = A^{-1}0 = 0$, so $x = y$. Hence for every $b$ there is exactly one solution, $x = A^{-1}b$.
