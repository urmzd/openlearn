# S-M11a q9

Claim (Gibbs' inequality): for distributions $p, q$ on a finite set with $q_i > 0$ wherever $p_i > 0$, $D_{KL}(p \,\Vert\, q) = \sum_{i:\, p_i > 0} p_i \log \frac{p_i}{q_i} \ge 0$, with equality exactly when $p = q$.

Method: the tangent-line bound $\log t \le t - 1$ for $t > 0$, with equality only at $t = 1$. (Proof of the bound: $\varphi(t) = t - 1 - \log t$ has $\varphi'(t) = 1 - 1/t$, negative on $(0, 1)$ and positive on $(1, \infty)$, so its unique minimum is $\varphi(1) = 0$.)

Let $S = \{i : p_i > 0\}$, the support of $p$. For $i \in S$, $t_i = q_i / p_i > 0$ by assumption. Then
$$-D_{KL}(p \,\Vert\, q) = \sum_{i \in S} p_i \log \frac{q_i}{p_i} \le \sum_{i \in S} p_i \left(\frac{q_i}{p_i} - 1\right) = \sum_{i \in S} q_i - \sum_{i \in S} p_i = \sum_{i \in S} q_i - 1 \le 0,$$
because $q$'s total mass is 1 and $S$ may not contain all of it. So $D_{KL}(p \,\Vert\, q) \ge 0$.

Equality: if $p = q$, every term is $p_i \log 1 = 0$. Conversely, if $D_{KL} = 0$, both inequalities above are equalities. The first forces $\log t_i = t_i - 1$, so $t_i = 1$, that is $q_i = p_i$, for every $i \in S$ (each $p_i > 0$ weights a nonnegative gap). The second forces $\sum_{i \in S} q_i = 1$, so $q_i = 0 = p_i$ off $S$. Hence $p = q$.

Consequences used later: cross-entropy $H(p, q) = H(p) + D_{KL}(p \,\Vert\, q) \ge H(p)$, so a model's loss on data from $p$ is minimized exactly when its predictions equal $p$; and `M11.1`'s property test asserts `kl(p, q) >= 0` on random pairs.
