# S-M11a q5

Claim: for discrete random variables $X, Y$ with joint distribution $P(x, y)$, marginal $P(x) = \sum_y P(x, y)$, and conditional $P(y \mid x) = P(x, y)/P(x)$ for $P(x) > 0$,
$$H(X, Y) = H(X) + H(Y \mid X), \qquad H(Y \mid X) = \sum_x P(x)\, H(Y \mid X = x),$$
with $H(X, Y) = -\sum_{x, y} P(x, y) \log P(x, y)$ and the convention $0 \log 0 = 0$.

Method: factor the joint probability inside the logarithm and split the sum.

Only pairs with $P(x, y) > 0$ contribute (the others are $0 \log 0 = 0$), and for those $P(x) > 0$ and $P(x, y) = P(x) P(y \mid x)$. So $\log P(x, y) = \log P(x) + \log P(y \mid x)$, and
$$H(X, Y) = -\sum_{x, y} P(x, y) \log P(x) \;-\; \sum_{x, y} P(x, y) \log P(y \mid x).$$
First sum: group by $x$ and use $\sum_y P(x, y) = P(x)$, giving $-\sum_x P(x) \log P(x) = H(X)$.
Second sum: write $P(x, y) = P(x) P(y \mid x)$, giving $\sum_x P(x) \left(-\sum_y P(y \mid x) \log P(y \mid x)\right) = \sum_x P(x) H(Y \mid X = x) = H(Y \mid X)$. Values $x$ with $P(x) = 0$ contribute nothing to either side.

So $H(X, Y) = H(X) + H(Y \mid X)$. Applied repeatedly, $H(X_1, \dots, X_T) = \sum_t H(X_t \mid X_{<t})$: an autoregressive model's total log-loss is the sum of its per-token conditional losses, which is why training on next-token cross-entropy fits the joint distribution of whole sequences.
