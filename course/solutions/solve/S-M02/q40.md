**Claim.** For every real $x$, $\left|\sin x - \left(x - \frac{x^3}{6}\right)\right| \le \frac{|x|^5}{120}$.

**Proof (direct, Taylor's theorem with the Lagrange remainder).** Let $f = \sin$. Its derivatives at 0 are $f(0) = 0$, $f'(0) = 1$, $f''(0) = 0$, $f'''(0) = -1$, $f^{(4)}(0) = 0$, so its degree 4 Taylor polynomial at 0 is $T_4(x) = x - \frac{x^3}{6}$ (the $x^4$ coefficient is 0, so it equals the degree 3 polynomial). Taylor's theorem with the Lagrange remainder gives, for each real $x \ne 0$, a point $c$ between 0 and $x$ with
$$\sin x - T_4(x) = \frac{f^{(5)}(c)}{5!} x^5, \qquad f^{(5)} = \cos .$$
Since $|\cos c| \le 1$ and $5! = 120$, $|\sin x - T_4(x)| \le \frac{|x|^5}{120}$. At $x = 0$ both sides are 0. So the inequality holds for every real $x$.
