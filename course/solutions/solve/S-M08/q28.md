# S-M08 q28

Claim: for $y = \mathrm{softmax}(x)$, $y_i = e^{x_i} / \sum_k e^{x_k}$, and upstream $g = \partial L / \partial y$, the input gradient is $\partial L / \partial x = y \odot (g - \langle g, y \rangle \mathbf{1})$.

Method: compute the Jacobian, then contract it with $g$.

Let $Z = \sum_k e^{x_k}$, so $\partial Z / \partial x_j = e^{x_j}$. By the quotient rule,
$$\frac{\partial y_i}{\partial x_j} = \frac{\delta_{ij} e^{x_i} Z - e^{x_i} e^{x_j}}{Z^2} = y_i (\delta_{ij} - y_j),$$
where $\delta_{ij}$ is 1 if $i = j$ and 0 otherwise.

By the chain rule, $(\partial L / \partial x)_j = \sum_i g_i \frac{\partial y_i}{\partial x_j} = \sum_i g_i y_i (\delta_{ij} - y_j) = g_j y_j - y_j \sum_i g_i y_i = y_j (g_j - \langle g, y \rangle)$.

In vector form, $\partial L/\partial x = y \odot (g - \langle g, y \rangle \mathbf{1})$. It costs $O(V)$ time and memory, never forming the $V \times V$ Jacobian $\mathrm{diag}(y) - y y^\top$. Its entries sum to $\sum_j y_j g_j - \langle g, y \rangle \sum_j y_j = 0$, as they must, since softmax is unchanged by adding a constant to every $x_j$.
