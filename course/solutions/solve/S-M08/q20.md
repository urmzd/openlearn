Claim: if $Y = XW$ and $dL = \operatorname{tr}(G^\top dY)$ with $G = \partial L/\partial Y$, then $\partial L/\partial W = X^\top G$ and $\partial L/\partial X = G W^\top$.

Method: differentials and the trace trick. For a scalar $L$ of a matrix $M$, $dL = \sum_{ij} \frac{\partial L}{\partial M_{ij}} dM_{ij} = \operatorname{tr}\!\left((\partial L/\partial M)^\top dM\right)$, so once $dL$ is written as $\operatorname{tr}(N^\top dM)$, the gradient is $N$ (the representation is unique because the $dM_{ij}$ are independent).

By the product rule, $dY = (dX) W + X (dW)$. Substituting and using linearity of the trace:
$$dL = \operatorname{tr}(G^\top (dX) W) + \operatorname{tr}(G^\top X\, dW).$$
Second term: $\operatorname{tr}(G^\top X\, dW) = \operatorname{tr}((X^\top G)^\top dW)$, so $\partial L / \partial W = X^\top G$.
First term: by the cyclic property $\operatorname{tr}(ABC) = \operatorname{tr}(CAB)$, $\operatorname{tr}(G^\top (dX) W) = \operatorname{tr}(W G^\top dX) = \operatorname{tr}((G W^\top)^\top dX)$, so $\partial L / \partial X = G W^\top$.

Shapes check: $X$ is $m \times k$, $W$ is $k \times n$, $G$ is $m \times n$; $X^\top G$ is $k \times n$ like $W$, and $G W^\top$ is $m \times k$ like $X$.
