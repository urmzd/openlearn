# S-M08 q16

Claim: for an invertible $n \times n$ matrix $X$, $d(X^{-1}) = -X^{-1} (dX) X^{-1}$.

Method: differentiate the defining identity. The differential $dF$ of a matrix function is its first-order change when $X$ changes by a small $dX$, and it obeys the product rule $d(AB) = (dA)B + A(dB)$ (expand $(A + dA)(B + dB)$ and drop the second-order term $dA\, dB$); the order of the factors must be kept, because matrices do not commute.

$X X^{-1} = I$ for every invertible $X$ near the current one, and $I$ does not change, so $dI = 0$. Taking differentials of both sides with the product rule:
$$(dX)\, X^{-1} + X\, d(X^{-1}) = 0 .$$
So $X\, d(X^{-1}) = -(dX) X^{-1}$. Multiplying on the left by $X^{-1}$:
$$d(X^{-1}) = -X^{-1} (dX)\, X^{-1} .$$
For $n = 1$ this is $d(1/x) = -dx/x^2$. Each entry: $\partial (X^{-1})_{ij} / \partial X_{kl} = -(X^{-1})_{ik} (X^{-1})_{lj}$.
