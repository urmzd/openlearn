# S-M08 q34

Claim: for $S = Q K^\top / \sqrt{d}$, $P = \mathrm{softmax}(S)$ by rows, $O = P V$, and upstream $dO = \partial L / \partial O$: $dV = P^\top dO$, $dP = dO\, V^\top$, $dS_{ij} = P_{ij} (dP_{ij} - \sum_k dP_{ik} P_{ik})$, $dQ = dS\, K/\sqrt{d}$, $dK = dS^\top Q / \sqrt{d}$.

Shapes: $Q, K$ are $T \times d$, $V$ is $T \times d_v$, $S$ and $P$ are $T \times T$, $O$ and $dO$ are $T \times d_v$.

Method: reverse mode through the three steps, each a rule already proved.

1. $O = PV$ is a matrix product. By q20 with $X = P$ and $W = V$: $dV = P^\top dO$ ($T \times d_v$, like $V$) and $dP = dO\, V^\top$ ($T \times T$, like $P$).
2. Row $i$ of $P$ is $\mathrm{softmax}$ of row $i$ of $S$, and rows do not interact. By q28 applied to row $i$ with upstream $dP_{i,:}$: $dS_{ij} = P_{ij}\,(dP_{ij} - \langle dP_{i,:}, P_{i,:}\rangle)$.
3. $S = Q K^\top / \sqrt{d}$ is a scaled product. By q20 with $X = Q$, $W = K^\top$, and the constant factor $1/\sqrt{d}$ carried through: $dQ = dS (K^\top)^\top / \sqrt{d} = dS\, K / \sqrt{d}$ ($T \times d$, like $Q$), and $d(K^\top) = Q^\top dS / \sqrt{d}$, so $dK = (Q^\top dS)^\top / \sqrt{d} = dS^\top Q / \sqrt{d}$ ($T \times d$, like $K$).

Every gradient has the shape of its variable. A causal mask sets masked $S_{ij}$ to $-\infty$, so $P_{ij} = 0$ there and step 2 gives $dS_{ij} = 0$: no gradient flows through masked entries. FlashAttention's backward (`L9.4`) recomputes $P$ tile by tile and uses exactly these rules, with $\sum_k dP_{ik} P_{ik} = \sum_k dO_{ik} O_{ik}$ precomputed per row.
