# S-M11b q7

Claim: for discrete $X, Y$ with joint distribution $P(x, y)$ and marginals $P(x) = \sum_y P(x, y)$, $P(y) = \sum_x P(x, y)$,
$$I(X; Y) = \sum_{x, y} P(x, y) \log \frac{P(x, y)}{P(x) P(y)} = H(X) + H(Y) - H(X, Y),$$
and $I(X; Y) \ge 0$ with equality exactly when $P(x, y) = P(x) P(y)$ for all $x, y$. Sums run over pairs with $P(x, y) > 0$ ($0 \log 0 = 0$); for those, $P(x) > 0$ and $P(y) > 0$.

Method: split the logarithm, then recognize a KL divergence.

Identity. $\log \frac{P(x, y)}{P(x) P(y)} = \log P(x, y) - \log P(x) - \log P(y)$, so
$$I(X; Y) = \sum_{x, y} P(x, y) \log P(x, y) - \sum_{x, y} P(x, y) \log P(x) - \sum_{x, y} P(x, y) \log P(y).$$
The first sum is $-H(X, Y)$. In the second, sum over $y$ first: $\sum_y P(x, y) = P(x)$, giving $\sum_x P(x) \log P(x) = -H(X)$; the third gives $-H(Y)$ the same way. So $I(X; Y) = -H(X, Y) + H(X) + H(Y)$.

Non-negativity. $Q(x, y) = P(x) P(y)$ is a distribution on pairs (non-negative, and $\sum_{x, y} P(x) P(y) = 1$), positive wherever $P(x, y) > 0$. The defining sum is exactly $D_{KL}(P \,\Vert\, Q)$, so Gibbs' inequality (S-M11a q9) gives $I(X; Y) \ge 0$.

Equality. Gibbs' inequality is an equality exactly when $P = Q$, that is $P(x, y) = P(x) P(y)$ for every pair, which is the definition of independence of $X$ and $Y$. So mutual information is zero for independent variables and positive otherwise; M11.4 computes it this way, as `kl` of the joint against the product of its marginals.
