# S-M11b q4

Claim: if $c_1, \dots, c_m$ are the codewords of a binary prefix code (no codeword is a prefix of another) with lengths $\ell_1, \dots, \ell_m$, then $\sum_{i=1}^m 2^{-\ell_i} \le 1$.

Method: count leaves of a complete binary tree.

Let $L = \max_i \ell_i$. Picture the complete binary tree of depth $L$: each node at depth $d$ is a binary string of length $d$, its children append 0 or 1, and it has $2^L$ leaves (the strings of length $L$). Codeword $c_i$ is the node at depth $\ell_i$, and the leaves below it are the strings of length $L$ that start with $c_i$: there are exactly $2^{L - \ell_i}$ of them (the remaining $L - \ell_i$ bits are free).

For $i \ne j$ these leaf sets are disjoint. If some leaf started with both $c_i$ and $c_j$, then the shorter of the two would be a prefix of the longer (both are prefixes of the same string), which the prefix property forbids; equal lengths would make them equal codewords.

Disjoint subsets of the $2^L$ leaves have sizes summing to at most $2^L$:
$$\sum_{i=1}^m 2^{L - \ell_i} \le 2^L .$$
Dividing by $2^L$ gives $\sum_i 2^{-\ell_i} \le 1$. Equality holds exactly when the codewords' leaf sets cover every leaf, a complete code such as every Huffman code (q2 b).
