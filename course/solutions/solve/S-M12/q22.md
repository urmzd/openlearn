# S-M12 q22

Claim: for $\ell(s) = \log(1 + e^{-z(ts + b)})$ with label $z \in \{1, -1\}$, temperature $t > 0$, and bias $b$, $\partial \ell / \partial s = -t z\, \sigma(-z(ts + b))$, and a pair's gradient does not involve any other pair's logit.

Method: chain rule through $u = z(ts + b)$.

Let $u = z(t s + b)$, so $\ell = \log(1 + e^{-u})$ and $du/ds = z t$. Then
$$\frac{d\ell}{du} = \frac{-e^{-u}}{1 + e^{-u}} = -\frac{1}{e^{u} + 1} = -\sigma(-u),$$
using $\sigma(v) = 1/(1 + e^{-v})$. By the chain rule,
$$\frac{\partial \ell}{\partial s} = \frac{d\ell}{du} \frac{du}{ds} = -t z\, \sigma\big(-z(ts + b)\big).$$
Note $-\log \sigma(u) = \log(1 + e^{-u})$, so this is the derivative of the loss as SigLIP writes it. For a positive pair with $t = 10$, $b = -10$, $s = 1$: $u = 0$, $\sigma(0) = 1/2$, and the gradient is $-5$ (q20 d).

**Independence.** SigLIP's batch loss is a sum of one such term per (image, text) pair, $\sum_{i, j} \ell(s_{ij}, z_{ij})$, where term $(i, j)$ depends only on $s_{ij}$, $z_{ij}$, $t$, and $b$. Differentiating the sum with respect to $s_{ij}$ therefore gives exactly the single term above: no other logit appears. In InfoNCE (q21) the softmax normalizer $\sum_k e^{s_k}$ couples every logit in a row, so each gradient depends on all of them; computing it needs the whole row of the similarity matrix at once, which is what makes softmax-based contrastive losses expensive to shard across devices and SigLIP's sigmoid loss cheap.
