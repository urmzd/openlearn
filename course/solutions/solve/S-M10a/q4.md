# S-M10a q4

Claim: if $f$ and $g$ are convex on $\mathbb{R}^n$, then $h = f + g$ is convex.

Definition: a function $\varphi: \mathbb{R}^n \to \mathbb{R}$ is convex when for all $x, y \in \mathbb{R}^n$ and every $t \in [0, 1]$, $\varphi(tx + (1-t)y) \le t\,\varphi(x) + (1 - t)\,\varphi(y)$: the function lies on or below every chord.

Method: direct, from the definition.

Fix $x, y \in \mathbb{R}^n$ and $t \in [0, 1]$, and let $z = tx + (1 - t)y$. Convexity of $f$ and of $g$ at the same $x, y, t$ gives
$$f(z) \le t f(x) + (1-t) f(y), \qquad g(z) \le t g(x) + (1-t) g(y).$$
Adding the two inequalities (adding inequalities that point the same way preserves the direction):
$$h(z) = f(z) + g(z) \le t\,(f(x) + g(x)) + (1 - t)\,(f(y) + g(y)) = t\,h(x) + (1-t)\,h(y).$$
Since $x$, $y$, and $t$ were arbitrary, $h = f + g$ is convex. The same argument with nonnegative weights shows any nonnegative combination of convex functions is convex, which is why a convex loss plus an $\ell_2$ penalty $\frac{\lambda}{2}\lVert w \rVert^2$ stays convex.
