# S-M03b q8

Claim: let $A = U\Sigma V^\top$ with $U$ ($m \times m$) and $V$ ($n \times n$) orthogonal and $\Sigma$ ($m \times n$) zero except for $\Sigma_{ii} = \sigma_i \ge 0$, $\sigma_1 \ge \sigma_2 \ge \dots$, $k = \min(m, n)$. Then (i) $A^\top A v_i = \sigma_i^2 v_i$ for each column $v_i$ of $V$ (with $\sigma_i = 0$ for $i > k$), so the singular values are the square roots of the eigenvalues of $A^\top A$; and (ii) $\max_{\lVert x \rVert = 1} \lVert Ax \rVert = \sigma_1$.

Method: substitute the decomposition and use $U^\top U = I$ and $V^\top V = I$.

(i) $A^\top A = V \Sigma^\top U^\top U \Sigma V^\top = V (\Sigma^\top \Sigma) V^\top$, and $\Sigma^\top \Sigma$ is the $n \times n$ diagonal matrix with entries $\sigma_1^2, \dots, \sigma_k^2$ followed by zeros. Multiply by $v_i = V e_i$: $A^\top A v_i = V(\Sigma^\top\Sigma) V^\top V e_i = V (\Sigma^\top \Sigma) e_i = \sigma_i^2 V e_i = \sigma_i^2 v_i$. So each $v_i$ is an eigenvector with eigenvalue $\sigma_i^2 \ge 0$; since the $v_i$ form a basis, these are all the eigenvalues, and $\sigma_i = \sqrt{\lambda_i(A^\top A)}$.

(ii) Let $\lVert x \rVert = 1$ and $c = V^\top x$, the coordinates of $x$ in the basis $v_1, \dots, v_n$; $\lVert c \rVert = \lVert x \rVert = 1$ because $V^\top$ is orthogonal. Then
$$\lVert Ax \rVert^2 = x^\top A^\top A x = c^\top (\Sigma^\top \Sigma) c = \sum_i \sigma_i^2 c_i^2 \le \sigma_1^2 \sum_i c_i^2 = \sigma_1^2 ,$$
using $\sigma_i \le \sigma_1$. So $\lVert Ax \rVert \le \sigma_1$ for every unit $x$. The bound is attained: for $x = v_1$, $c = e_1$ and $\lVert A v_1 \rVert^2 = \sigma_1^2$. Hence the maximum is $\sigma_1$, the spectral norm $\lVert A \rVert_2$; this is why Eckart-Young's error $\lVert A - A_r \rVert_2$ is $\sigma_{r+1}$, the largest singular value left in $A - A_r$.
