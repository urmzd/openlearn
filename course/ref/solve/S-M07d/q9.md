# S-M07d q9

**Setup.** Examples $(x_i, y_i)$, $i = 1, \dots, n$, with $x_i \in \mathbb{R}^d$ and $y_i \in \{0, 1\}$; $X$ is the $n \times d$ matrix with rows $x_i$; $w \in \mathbb{R}^d$; $\sigma(z) = 1/(1 + e^{-z})$; $p_i = \sigma(x_i \cdot w)$ and $p$ the vector of the $p_i$; $\lambda \ge 0$. The loss is a sum over examples plus the penalty:

$$L(w) = \sum_i \ell_i(w) + \tfrac{\lambda}{2}\lVert w\rVert^2, \qquad \ell_i(w) = -[y_i \ln p_i + (1 - y_i)\ln(1 - p_i)].$$

**Gradient and Hessian.** With $z_i = x_i \cdot w$, $\ln p_i = -\ln(1 + e^{-z_i})$ and $\ln(1 - p_i) = -z_i - \ln(1 + e^{-z_i})$, so $\ell_i = \ln(1 + e^{-z_i}) + (1 - y_i) z_i$ and $d\ell_i/dz_i = -(1 - p_i) + (1 - y_i) = p_i - y_i$. By the chain rule $\nabla \ell_i = (p_i - y_i)\, x_i$, and since $\sigma'(z) = \sigma(z)(1 - \sigma(z))$, $\nabla^2 \ell_i = p_i(1 - p_i)\, x_i x_i^\top$. Summing,

$$\nabla L(w) = X^\top (p - y) + \lambda w, \qquad H(w) = \nabla^2 L(w) = X^\top S X + \lambda I, \quad S = \mathrm{diag}(p_i(1 - p_i)).$$

**Positive semidefinite Hessian.** For every $v \in \mathbb{R}^d$,

$$v^\top H v = \sum_i p_i(1 - p_i)\,(x_i \cdot v)^2 + \lambda \lVert v\rVert^2 \ge 0,$$

because $0 < p_i < 1$ makes each weight $p_i(1 - p_i)$ positive and the squares are non-negative. When $\lambda > 0$ and $v \ne 0$ the last term is strictly positive, so $H$ is positive definite.

**Conclusion.** A twice differentiable function whose Hessian is positive semidefinite everywhere is convex, so $L$ is convex, and strictly convex when $\lambda > 0$. For a convex differentiable $L$, $L(u) \ge L(w) + \nabla L(w) \cdot (u - w)$ for all $u$, so a stationary point ($\nabla L(w) = 0$) satisfies $L(u) \ge L(w)$ for every $u$: it is a global minimum (and the unique one when $\lambda > 0$). Newton's step solves $H(w)\,\Delta = -\nabla L(w)$; when $\lambda > 0$, $H$ is positive definite and hence invertible, so the linear system has exactly one solution and the step is well defined.
