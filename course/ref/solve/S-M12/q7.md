# S-M12 q7

Claim: for every input $x$ of shape $[N, C, H, W]$ and every column array $Y$ of shape $[N, C k_h k_w, P Q]$, $\langle \operatorname{im2col}(x), Y \rangle = \langle x, \operatorname{col2im}(Y) \rangle$.

Method: write im2col as a copy with an index map, expand the inner product, and regroup the sum by input pixel.

Index the column entries by $\alpha = (n, c, r, s, p, q)$. im2col copies one pixel into each entry: with padding $(p_h, p_w)$, stride $(s_h, s_w)$, and dilation $(d_h, d_w)$, entry $\alpha$ reads position
$$\pi(\alpha) = (n, c, p s_h + r d_h - p_h, q s_w + s d_w - p_w)$$
of the input, and is 0 when $\pi(\alpha)$ falls in the padding (outside $[0, H) \times [0, W)$). Let $A$ be the set of entries whose $\pi(\alpha)$ is a real pixel. Then
$$\operatorname{im2col}(x)_\alpha = \begin{cases} x_{\pi(\alpha)} & \alpha \in A \\ 0 & \text{otherwise.}\end{cases}$$

Expand the left side:
$$\langle \operatorname{im2col}(x), Y \rangle = \sum_\alpha \operatorname{im2col}(x)_\alpha Y_\alpha = \sum_{\alpha \in A} x_{\pi(\alpha)} Y_\alpha .$$
Group the terms by the pixel $u = \pi(\alpha)$ they read. Every $\alpha \in A$ reads exactly one pixel, so the groups partition $A$:
$$\sum_{\alpha \in A} x_{\pi(\alpha)} Y_\alpha = \sum_u x_u \Big( \sum_{\alpha \in A,\ \pi(\alpha) = u} Y_\alpha \Big).$$
The inner sum is, by definition, col2im: it sends each column entry back to the pixel it was copied from, adds the entries that land on the same pixel (overlapping windows), and drops entries copied from the padding (those $\alpha \notin A$ have no pixel). So the inner sum is $\operatorname{col2im}(Y)_u$, and
$$\langle \operatorname{im2col}(x), Y \rangle = \sum_u x_u \operatorname{col2im}(Y)_u = \langle x, \operatorname{col2im}(Y) \rangle .$$

Since this holds for all $x$ and $Y$, col2im is the adjoint (the transpose, as a matrix) of the linear map im2col. In particular, assigning instead of adding in col2im keeps one term of each inner sum and breaks the identity wherever windows overlap.
