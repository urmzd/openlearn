# S-M12 q24

Claim: $\text{WER}(r, h) = d(r, h) / |r|$, with $d$ the word-level edit distance and $|r|$ the number of reference words, is not a metric, because it is not symmetric.

Method: a counterexample computed in both directions.

Take $a = $ "the cat" (2 words) and $b = $ "the" (1 word).

- Reference $a$, hypothesis $b$: the cheapest alignment matches "the" and deletes "cat", so $d(a, b) = 1$ and $\text{WER}(a, b) = 1/2$.
- Reference $b$, hypothesis $a$: matching "the" and inserting "cat" costs $d(b, a) = 1$ (no alignment costs 0, since the lengths differ), and $\text{WER}(b, a) = 1/1 = 1$.

So $\text{WER}(a, b) = 1/2 \ne 1 = \text{WER}(b, a)$: the symmetry axiom $d(x, y) = d(y, x)$ fails, and WER is not a metric.

Why: the edit distance itself is symmetric (an insertion one way is a deletion the other way, and substitutions are symmetric), so the numerator is the same in both directions. The asymmetry is entirely in the denominator, which is the length of whichever sequence plays the reference. The same normalization is why WER can exceed 1: insertions count against the reference length (q23, "oh hello there" against "hello" has WER 2).
