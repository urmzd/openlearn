# S-M09b q17

**Claim.** For $a > 0$ and the iteration $y_{k+1} = y_k(3 - a y_k^2)/2$, the relative error $e_k = 1 - \sqrt{a}\,y_k$ satisfies $e_{k+1} = (3e_k^2 - e_k^3)/2$, so the iteration converges quadratically to $1/\sqrt{a}$ once $e_k$ is small.

**Proof.** From the definition, $y_k = (1 - e_k)/\sqrt{a}$, so $a y_k^2 = (1 - e_k)^2$. Substituting into the update and multiplying by $\sqrt{a}$,

$$\sqrt{a}\,y_{k+1} = \frac{(1 - e_k)\bigl(3 - (1 - e_k)^2\bigr)}{2}.$$

Expand: $3 - (1 - e_k)^2 = 2 + 2e_k - e_k^2$, and

$$(1 - e_k)(2 + 2e_k - e_k^2) = 2 + 2e_k - e_k^2 - 2e_k - 2e_k^2 + e_k^3 = 2 - 3e_k^2 + e_k^3.$$

So $\sqrt{a}\,y_{k+1} = 1 - (3e_k^2 - e_k^3)/2$, and reading off $e_{k+1} = 1 - \sqrt{a}\,y_{k+1}$,

$$e_{k+1} = \frac{3e_k^2 - e_k^3}{2}.$$

**Quadratic convergence.** If $\lvert e_0\rvert \le 1/2$, then $\lvert e_{k+1}\rvert \le \lvert e_k\rvert^2 (3 + \lvert e_k\rvert)/2 \le \tfrac{7}{4}\lvert e_k\rvert^2 \le \tfrac{7}{8}\lvert e_k\rvert$, so $e_k \to 0$ and $y_k \to 1/\sqrt{a}$. Then $e_{k+1}/e_k^2 = (3 - e_k)/2 \to 3/2$, a finite non-zero constant: the convergence is quadratic, and the number of correct bits roughly doubles each step (for example $e_0 = 2^{-4}$ gives $e_1 = 47/8192 \approx 2^{-7.4}$).
