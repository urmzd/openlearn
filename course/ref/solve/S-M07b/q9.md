# S-M07b q9

**Claim.** Let $c_1, \dots, c_V \ge 0$ with $N = c_1 + \dots + c_V > 0$. Over all probability vectors $p$ ($p_k \ge 0$, $\sum_k p_k = 1$), the log-likelihood $\ell(p) = \sum_k c_k \ln p_k$ is maximized by $\hat p_k = c_k / N$, using the convention $0 \ln 0 = 0$.

**Zero counts.** If some $p_k = 0$ with $c_k > 0$, then $c_k \ln p_k = -\infty$ and $\ell(p) = -\infty$, so such $p$ is never a maximizer; we may assume $p_k > 0$ wherever $c_k > 0$. Terms with $c_k = 0$ contribute $0$ whatever $p_k$ is, and $\hat p_k = 0$ there.

**Proof (Gibbs' inequality).** Let $S = \{k : c_k > 0\}$. Write $\hat p_k = c_k / N$, so

$$\ell(p) = N \sum_{k \in S} \hat p_k \ln p_k = N \sum_{k \in S} \hat p_k \ln \hat p_k - N \sum_{k \in S} \hat p_k \ln \frac{\hat p_k}{p_k} = -N\bigl(H(\hat p) + \mathrm{KL}(\hat p \,\Vert\, p)\bigr),$$

where $H(\hat p) = -\sum_{k \in S} \hat p_k \ln \hat p_k$ does not depend on $p$, and $\mathrm{KL}(\hat p \Vert p) = \sum_{k \in S} \hat p_k \ln(\hat p_k / p_k)$.

The KL divergence is non-negative. Since $\ln t \le t - 1$ with equality only at $t = 1$,

$$-\mathrm{KL}(\hat p \Vert p) = \sum_{k \in S} \hat p_k \ln \frac{p_k}{\hat p_k} \le \sum_{k \in S} \hat p_k \Bigl(\frac{p_k}{\hat p_k} - 1\Bigr) = \sum_{k \in S} p_k - 1 \le 0,$$

with equality only if $p_k = \hat p_k$ for every $k \in S$ and $\sum_{k \in S} p_k = 1$, that is, $p_k = 0$ off $S$. So $\ell(p) \le -N H(\hat p) = \ell(\hat p)$, with equality exactly at $p = \hat p$. Hence $p_k = c_k / N$ is the unique maximizer.
