# L10.1 deviations

- Replaced `tl-sys`/C kernel operations with `candle-core` and `candle-nn` 0.10.2 while keeping the model layers learner-written, as required by the Step B design decision.
- Candle's tensor kernels produce small floating-point differences between incremental decode and full prefill (observed maximum absolute difference: `0.000007390976`). The test now uses a `2e-5` tolerance instead of bit-for-bit equality.
- The final guarded `ol verify course L10.1` passed after adjusting the tolerance, title, annotation, and dependency mirrors: all 22 mutants were killed and all checks passed.
- On Linux CPU (x86_64), Candle's gemm sends a one-row product down a matrix-vector path and a taller one down a blocked kernel, so the original reference failed `batched_forward_equals_single` (last-bit differences) and `incremental_decode_equals_full_prefill` (max diff `0.0018`, after f16 key rounding amplified them). The reference now computes every product one row at a time (`model::matmul_rows`) and attends each query over exactly its visible keys, which makes it batch-invariant by construction; both tests pass unchanged on linux/amd64.
