# Writing Systems

Mandarin is written with **Chinese characters** (汉字, Hànzì). Mainland China uses **simplified** characters. Taiwan and Hong Kong use **traditional** characters. **Pinyin** is the Latin-letter spelling used to teach pronunciation and to type. This chapter teaches how characters are built, the characters a beginner must read first, and how to type Chinese.

---

## How Characters Work

### One Character, One Syllable

Each character is one syllable and usually one unit of meaning. Most words have two characters. Chinese text has no spaces between words.

| English | Chinese | Pinyin | Notes |
|---------|---------|--------|-------|
| electricity | 电 | diàn | One character, one syllable |
| speech | 话 | huà | One character, one syllable |
| telephone | 电话 | diànhuà | "electric speech" |
| brain | 脑 | nǎo | One character, one syllable |
| computer | 电脑 | diànnǎo | "electric brain" |
| ladder | 梯 | tī | One character, one syllable |
| elevator | 电梯 | diàntī | "electric ladder" |

When you learn one character, you get a piece of many words.

### Four Ways Characters Are Built

| Type | How it works | Examples |
|------|--------------|----------|
| Picture | A simple drawing of the thing | 人 rén (person), 山 shān (mountain), 口 kǒu (mouth), 木 mù (tree) |
| Symbol | A sign for an idea | 一 yī (one), 二 èr (two), 上 shàng (up), 下 xià (down) |
| Combined meaning | Two meaning parts joined | 好 hǎo (good) = 女 woman + 子 child. 明 míng (bright) = 日 sun + 月 moon |
| Meaning part plus sound part | One part hints at the meaning, one part hints at the sound | 妈 mā (mother) = 女 woman (meaning) + 马 mǎ (sound) |

More than 80 percent of characters are the last type. The meaning part is called the **radical** (部首, bùshǒu). The other part is the **phonetic component**.

### Phonetic Components

A phonetic component gives the approximate sound. The tone, and sometimes the initial, can differ.

| Sound part | Its reading | Characters that share it |
|------------|-------------|--------------------------|
| 马 | mǎ | 妈 mā (mother), 吗 ma (question particle), 骂 mà (to scold), 码 mǎ (code) |
| 青 | qīng | 请 qǐng (please), 清 qīng (clear), 情 qíng (feeling), 晴 qíng (sunny) |
| 方 | fāng | 房 fáng (house), 放 fàng (to put), 访 fǎng (to visit), 防 fáng (to guard) |
| 包 | bāo | 饱 bǎo (full), 跑 pǎo (to run), 抱 bào (to hug), 泡 pào (to soak) |
| 门 | mén | 们 men (plural), 问 wèn (to ask), 闻 wén (to smell) |
| 巴 | bā | 吧 ba (particle), 把 bǎ (to hold), 爸 bà (dad) |
| 生 | shēng | 姓 xìng (surname), 星 xīng (star), 性 xìng (nature), 胜 shèng (to win) |
| 交 | jiāo | 饺 jiǎo (dumpling), 较 jiào (to compare), 校 xiào (school) |

Use both parts to make a guess. 饺 has the food radical 饣 and the sound part 交 (jiāo). It is a food word that sounds like jiao: 饺子 (jiǎozi), dumpling.

## Strokes

### The Eight Basic Strokes

| Stroke name | Pinyin | English | Direction | Example characters |
|-------------|--------|---------|-----------|--------------------|
| 横 | héng | Horizontal | Left to right | 一, 二, 十 |
| 竖 | shù | Vertical | Top to bottom | 十, 中, 下 |
| 撇 | piě | Left-falling | Top right to bottom left | 人, 八, 少 |
| 捺 | nà | Right-falling | Top left to bottom right | 人, 大, 八 |
| 点 | diǎn | Dot | Short, down to the right | 六, 小, 主 |
| 提 | tí | Rising | Bottom left to top right | 我, 打, 汉 |
| 折 | zhé | Turn | One stroke that changes direction | 口, 日, 五 |
| 钩 | gōu | Hook | A small flick at the end of a stroke | 小, 水, 你 |

### Stroke Order Rules

Correct stroke order makes characters balanced. It also makes handwriting input on a phone work.

| Rule | Example | How |
|------|---------|-----|
| 1. Top to bottom | 三 | Write the top line first and the bottom line last |
| 2. Left to right | 你 | Write the left part 亻 first, then the right part |
| 3. Horizontal before vertical | 十 | Write the horizontal stroke, then the vertical stroke through it |
| 4. Left-falling before right-falling | 人 | Write the stroke that falls left, then the stroke that falls right |
| 5. Outside before inside | 月, 同 | Write the frame, then the strokes inside it |
| 6. Close the frame last | 国, 日 | Write the frame, fill the inside, then close the bottom |
| 7. Center before the two sides | 小, 水 | Write the middle stroke, then the left, then the right |
| 8. A bottom-left enclosure is written last | 这, 远 | Write the inside part first, then 辶 |

## Pinyin Input

Chinese speakers type with **pinyin input** (拼音输入法, pīnyīn shūrùfǎ). You type the pinyin without tones. The keyboard shows a row of matching characters. You pick one.

### Setting It Up

Menu names change between system versions. The path is close to the one below.

| Device | Steps |
|--------|-------|
| iPhone, iPad | Settings, General, Keyboard, Keyboards, Add New Keyboard, Chinese (Simplified), Pinyin QWERTY |
| Android with Gboard | Gboard settings, Languages, Add keyboard, Chinese (Simplified), Pinyin |
| Mac | System Settings, Keyboard, Text Input, Edit, the plus button, Chinese (Simplified), Pinyin |
| Windows | Settings, Time and language, Language and region, Add a language, Chinese (Simplified, China) |

### How to Type

| You type | The keyboard offers | Tip |
|----------|---------------------|-----|
| nihao | 你好 | Type whole words. Do not type one character at a time |
| xiexie | 谢谢 | The first candidate is usually correct for common words |
| woxianghecha | 我想喝茶 | You can type a whole phrase with no spaces |
| shi | 是, 时, 十, 事, 市 | A single syllable gives many candidates. You must choose |
| lv | 绿, 旅, 律 | Type v for ü after l and n |
| nv | 女 | Type v for ü after l and n |
| xian | 先, 现, 线 | One syllable |
| xi'an | 西安 | The apostrophe splits two syllables |
| zdl | 知道了 | The first letter of each syllable works for common phrases |

### Keys and Switching

| Action | Phone | Mac | Windows |
|--------|-------|-----|---------|
| Switch between Chinese and English | Globe key | Caps Lock or Control and Space | Shift |
| Accept the first candidate | Tap it or press space | Space | Space |
| Choose another candidate | Tap it | Number key | Number key |
| Keep the Latin letters you typed | Tap the letters | Return | Enter |
| Type the list comma 、 | Symbol page | Backslash key in Chinese mode | Backslash key in Chinese mode |

### When You Cannot Read a Character

- **Handwriting input** (手写输入, shǒuxiě shūrù): Add the Chinese handwriting keyboard and draw the character with your finger. Correct stroke order improves the result.
- **Voice input** (语音输入, yǔyīn shūrù): Speak, and the phone writes characters. This is also a good pronunciation test.
- **Copy and paste:** Press and hold a message to copy the text into a dictionary app.
- **Tone marks:** Chinese speakers never type tone marks. To write pinyin with tones in your notes on a Mac, use the ABC Extended keyboard: Option and a for the first tone, Option and e for the second, Option and v for the third, Option and the grave key for the fourth, then the vowel. On most phone keyboards, press and hold a vowel key to see marked letters.
