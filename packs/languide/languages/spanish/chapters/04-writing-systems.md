## The Spanish Alphabet

Spanish uses the Latin alphabet with **27 letters** — the standard 26 plus **ñ**. The letters **ch** and **ll** were historically separate letters but are no longer treated as such in modern alphabetical ordering.

### Letters Rarely Used

**K** and **W** appear almost exclusively in borrowed words (kilo, whisky, wifi).

## Accent Marks (Tildes)

Spanish uses only one type of accent mark: the **acute accent** (´), which goes over vowels: **á, é, í, ó, ú**.

### What Accent Marks Do

| Function | Example | Explanation |
|----------|---------|-------------|
| Indicate stress | ca**fé**, te**lé**fono, es**ta**ción | Stress falls on the marked syllable |
| Distinguish homophones | sí (yes) vs. si (if) | Different words, same spelling otherwise |
| Mark question words | ¿**qué**? ¿**dónde**? ¿**cuándo**? | Always accented in questions/exclamations |

### Words Travelers Will See with Accents

|------|---------------|---------|

| farmacia | fahr-MAH-syah | pharmacy (no accent — regular stress) |

## The Dieresis (ü)

The **ü** (u with dieresis) appears only in the combinations **güe** and **güi**, where it indicates the **u** must be pronounced (normally u is silent after g before e/i).

| With ü (u pronounced) | Without ü (u silent) |
|------------------------|---------------------|
| bilin**güe** (bee-LEEN-gweh) = bilingual | **gue**rra (GEH-rrah) = war |
| ver**güe**nza (behr-GWEHN-sah) = shame | **gui**tar (gee-TAHR) = to guide |
| pin**güi**no (peen-GWEE-noh) = penguin | **gui**a (GEE-ah) = guide |

## Inverted Punctuation: ¿ and ¡

Spanish is unique in using **inverted question and exclamation marks** at the **beginning** of questions and exclamations. This helps readers know the sentence's tone from the start.

### Examples

| Type | Spanish | Notes |
|------|---------|-------|
| Question | **¿**Dónde está el hotel**?** | ¿ at start, ? at end |
| Exclamation | **¡**Qué bonito**!** | ¡ at start, ! at end |
| Mixed | **¿**Cuánto cuesta**?** **¡**Es muy caro**!** | Each sentence gets its own marks |
| Mid-sentence | Señor, **¿**puede ayudarme**?** | ¿ starts where the question begins |

**Note:** In casual texting and social media, many Spanish speakers drop the inverted marks. In formal writing, they're always required.

## Typing Special Characters

### On a Phone

Most phone keyboards offer Spanish characters by **long-pressing** the base letter:
- Long-press **a** → á, Long-press **n** → ñ
- Add a Spanish keyboard in your phone settings for the easiest experience

### On a Computer

| Character | Windows (US keyboard) | Mac (US keyboard) | Alternative |
|-----------|----------------------|-------------------|-------------|
| á | Alt + 0225 | Option + e, then a | |
| é | Alt + 0233 | Option + e, then e | |
| í | Alt + 0237 | Option + e, then i | |
| ó | Alt + 0243 | Option + e, then o | |
| ú | Alt + 0250 | Option + e, then u | |
| ñ | Alt + 0241 | Option + n, then n | |
| ü | Alt + 0252 | Option + u, then u | |
| ¿ | Alt + 0191 | Option + Shift + ? | |
| ¡ | Alt + 0161 | Option + 1 | |

**Tip:** Adding an international or Spanish keyboard layout is the easiest long-term solution.

## Number Formatting

Spanish-speaking countries format numbers differently from English.

### Decimal and Thousands Separators

| Convention | Example | Where Used |
|------------|---------|-----------|
| Period for thousands, comma for decimal | 1.500,50 | Spain, Argentina, and most of LatAm |
| Comma for thousands, period for decimal | 1,500.50 | Mexico, Puerto Rico |

### Currency Display

| Country | Currency | Format Example |
|---------|----------|---------------|
| Spain | Euro (€) | 15,50 € |
| Mexico | Peso (MXN, $) | $1,500.00 |
| Argentina | Peso (ARS, $) | $1.500,00 |
| Colombia | Peso (COP, $) | $50.000 |

### Date Format

Spanish-speaking countries use **day/month/year** (not month/day/year):
- **15/03/2026** = March 15, 2026
- **Written:** 15 de marzo de 2026

### Time Format

| Format | Example | Usage |
|--------|---------|-------|
| 24-hour | 14:30 | Official schedules, Spain |
| 12-hour | 2:30 p.m. | Casual speech, some LatAm countries |

### Telling Time

| It's 1:00 | Es la una |

| It's 3:30 | Son las tres y media |
| It's 4:15 | Son las cuatro y cuarto |
| It's 4:45 | Son las cinco menos cuarto |
| At 8 in the morning | A las ocho de la mañana |
| At 9 at night | A las nueve de la noche |
